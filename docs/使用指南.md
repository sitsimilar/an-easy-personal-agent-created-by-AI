# 个人信息管家 · 桌面版使用指南

> 版本：v1.0（MVP） · 适用：Windows 桌面伴侣程序 + Web 主界面

---

## 一、产品简介

「个人信息管家」是一个面向程序员的个人智能助理，帮你把两件事做到"无感"：

1. **个人第二大脑**：随时记下零散的想法、资料、待办，系统自动分类、总结、关联，找得到、用得上。
2. **代码分析常驻陪伴**：当你启动 Visual Studio 写代码时，桌面伴侣会自动唤醒，读取解决方案代码并给出优化建议，通过悬浮窗推送，无需手动触发。

数据全部存储在云端，登录后多端同步。

---

## 二、安装与启动

### 2.1 三种安装方式（任选其一）

| 方式 | 文件 | 说明 |
|---|---|---|
| 安装版（推荐） | `个人信息管家 Setup 1.0.0.exe` | 双击安装，可选安装目录，自动创建桌面和开始菜单快捷方式 |
| 轻量版 | `个人信息管家-轻量版-2.6.0.exe` | 免安装，双击直接运行 |
| 绿色版 | `win-unpacked/` 目录 | 解压即用，运行其中的 `个人信息管家.exe` |

### 2.2 系统要求

- Windows 10 / 11（64 位）
- 首次使用需联网（登录、数据同步、AI 能力均走云端）
- 若要使用「VS 代码分析」功能，需本机已安装 **Visual Studio**

### 2.3 启动

- 程序启动后**不会弹出大窗口**，而是静默驻留在**系统托盘**（右下角图标）+ 一个**悬浮窗**（默认屏幕右下角）。
- 若未看到托盘图标，点击任务栏右下角的"^"展开隐藏图标即可找到。

---

## 三、首次登录

1. 首次使用时，从托盘菜单点「打开主界面」，或直接在悬浮窗内操作。
2. 输入**手机号** → 点「获取验证码」→ 输入短信验证码 → 登录。
3. 登录态会自动保持，下次启动无需重复登录。

> 说明：桌面端目前支持**手机号验证码登录**；微信扫码登录仅限浏览器 Web 版使用。

## 四、界面总览

### 4.1 系统托盘菜单

右键点击托盘图标，弹出菜单：

| 菜单项 | 作用 |
|---|---|
| 显示 / 隐藏悬浮窗 | 切换悬浮窗显隐 |
| 打开主界面 | 在浏览器打开完整 Web 主界面 |
| 立即分析当前 VS 项目 | 手动触发一次代码分析 |
| 暂停 / 恢复 VS 监听 | 开关自动分析 |
| 退出 | 退出桌面伴侣程序 |

### 4.2 悬浮窗（置顶小窗）

- **位置与拖动**：默认屏幕右下角，可拖动、可吸附屏幕边缘、可折叠成窄条。
- **快速记录**：一键输入想法/待办，回车即存，不用切换窗口。
- **建议卡片**：VS 分析完成后自动弹出优化建议，支持「展开详情 / 稍后 / 忽略」。
- **状态提示**：显示"已监听 VS / 分析中…"等状态。
- **快捷入口**：打开主界面。

### 4.3 主界面（Web 版）

在浏览器打开完整功能（地址：`https://your-app.workbuddy.host/`）：

| 区域 | 说明 |
|---|---|
| 顶部搜索栏 | 关键词检索（想法、资料、待办全文模糊匹配） |
| 左侧导航 | 全部信息 / 想法 / 资料 / 待办 / 分类标签 / VS 代码分析 / 设置 |
| 主内容区 | 记录卡片列表（分类标签、摘要、时间）+ 排序筛选 |
| 记录详情 | 全文、AI 摘要、相关记录、编辑/删除 |
| 待办视图 | 待办列表，勾选完成、优先级、提醒时间 |
| 回收站 | 删除的记录保留 30 天，可恢复或彻底删除 |

## 五、核心功能

### 5.1 记录想法 / 资料 / 待办

点击主界面或悬浮窗的「＋」，选择类型：

- **想法**：一闪而过的灵感，输入文字即可。
- **资料**：支持粘贴链接，或上传文件（图片 / PDF / 常见文档，单文件 ≤ 50MB）。
- **待办**：可设优先级（高/中/低）和提醒时间，完成后勾选。

### 5.2 自动分类 / 总结 / 关联

- 新建记录后约 5 秒内，AI 会**自动打标签分类**、**生成摘要**，并**关联**历史相关内容。
- 打开某条记录时，详情页会展示"相关记录"列表，帮助你串起零散信息。
- 分类标签可手动修正。

### 5.3 关键词检索

- **检索**：顶部输入关键词，全文 + 标签 + 分类模糊匹配，响应约 2 秒内。

### 5.4 VS 代码分析（核心特色）

1. **自动触发**：启动 Visual Studio 写代码时，桌面伴侣自动检测到 `devenv.exe` 进程（约 3 秒轮询）。
2. **读取代码**：自动解析当前解决方案（`.sln` → 项目 `.csproj` → 源码文件）。
3. **智能分析**：云端大模型分析代码，输出结构化优化建议（含严重级别：错误/警告/建议、涉及文件、改进方案）。
4. **推送建议**：分析结果通过悬浮窗卡片推送，可展开/稍后/忽略；完整历史可在主界面「VS 代码分析」页查看。
5. **增量分析**：只分析有变更的文件（本地缓存文件 hash），不会每次全量重复分析。

> 性能目标：VS 启动后 ≤10 秒触发分析，≤30 秒收到首条建议。

## 六、设置与隐私

在主界面「设置」页可配置：

| 设置项 | 说明 |
|---|---|
| 账号信息 | 当前登录账号 |
| VS 路径 | Visual Studio 安装路径（通常自动识别） |
| 悬浮窗偏好 | 是否启用悬浮窗、位置尺寸 |
| 通知开关 | 是否接收分析/提醒通知 |
| **代码上传开关** | 关闭后，桌面伴侣**不再读取、不上传任何源码**（隐私保护） |

**隐私说明**：

- 所有数据存储在云端，并**按账号严格隔离**，他人无法访问你的数据。
- 代码分析默认会把源码发送到云端大模型处理；如介意，可在设置中**关闭代码上传**，此时 VS 分析功能停用，但其余功能不受影响。
- 已删除的记录进入回收站保留 30 天，可恢复。

## 七、常见问题（FAQ）

**Q1：托盘图标不见了？**
点击任务栏右下角"^"展开隐藏图标，把"个人信息管家"拖到托盘即可。

**Q2：启动 VS 后没收到代码分析？**
- 确认托盘菜单处于"暂停 VS 监听"状态时点一下恢复；
- 确认设置里「代码上传开关」为开启；
- VS 若从开始菜单/图标启动（无命令行参数），伴侣会尝试读取 VS 最近项目，失败会提示"未检测到解决方案"，可用「立即分析当前 VS 项目」手动触发。

**Q3：悬浮窗挡到工作区了？**
悬浮窗可拖动到任意位置、吸附屏幕边缘，或折叠成窄条；也可在设置里关闭悬浮窗。

**Q4：换电脑后数据还在吗？**
在。数据存云端，新设备用同一手机号登录即可同步。

**Q6：怎么卸载？**
- 安装版：Windows「设置 → 应用」中卸载，或用安装包自带的卸载程序。
- 轻量版/绿色版：直接删除文件即可。
