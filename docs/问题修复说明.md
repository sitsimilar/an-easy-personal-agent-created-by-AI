## 逐项完成情况

### 问题 3（中/P1）：思维树导出/导入 JSON —— 已修复

- **根因**：思维树林仅存 `localStorage`（键 `personal-agent.mindforest.v1`），无跨设备迁移与备份手段。
- **修复内容**：
  - `web/src/services/mindforest-store.ts` 新增纯函数 `serializeForestStore(store)`（序列化为 JSON 字符串）与 `deserializeForestStore(raw)`（解析 + `validateForestStore` 校验，非法返回 null）。
  - `web/src/pages/MindTreePage.tsx` 左侧栏（ForestSidebar 下方）新增「导出 JSON」「导入 JSON」两个按钮（带 Tooltip 说明）。导出走浏览器下载 `.json` 文件；导入经隐藏 `<input type="file">` 读取后校验，成功则整店替换并切到第一棵树，失败则错误提示不覆盖现有数据。
- **说明**：本项采用「导出/导入 JSON」方案（更轻量、无需依赖云库 schema 变更）。后续若要自动跨端同步，可复用云库新增 settings 型表（见「下一步优化」）。

### 问题 4（中/P1）：各页面错误重试按钮 + 差异化文案 —— 已修复

- v2.8.0 已落地错误分类（登录失效/网络/服务不可用/参数错误 → `classifyError` + `friendlyError` 差异化文案），本项补齐各页「重试」入口。
- **修复内容**（均复用 `load()` / `generate()` 等现成重试逻辑）：
  - `HomePage.tsx`：错误态增加「重试加载」按钮（RefreshIcon）。
  - `RecordsPage.tsx`：错误态增加「重试加载」按钮。
  - `RecyclePage.tsx`：错误提示旁增加「重试」按钮。
  - `TodoPage.tsx`：错误提示旁增加「重试」按钮。
  - `ReviewPage.tsx`：错误提示旁增加「重试」按钮。
- 差异化文案由 `friendlyError` 按 `classifyError` 结果返回（登录失效提示重新登录、网络提示检查网络等），各页无需再重复分支。

### 问题 5（中/P2）：根卡片「还原」按钮 —— 不适用

- **核实结果**：全库 grep「还原」，仅命中三处，均为正常语义、非问题所述按钮：
  - `WindowControls.tsx`：标题栏窗口控制「最小化/最大化-还原」的 `aria-label`（语义正确）。
  - `PenInkLayer.tsx`：注释「由归一化还原为像素」（非按钮）。
- 思维树根卡片（`MindTreeNodeView.tsx`）实际按钮为「重新生成全部分支 / 删除整棵树 / 添加一个思考点」，无「还原」字样；`PenInkLayer` 的清空按钮用 `title="清除笔迹"`（DeleteIcon），语义清晰。
- **结论**：所述「还原」按钮在代码中不存在，标记为**不适用**，无需修改。

### 问题 6（低/P2）：登录页体验 —— 已修复

- **修复内容**（`LoginPage.tsx`）：
  1. 错误提示从卡片底部移到「验证码输入框」与「登录按钮」之间，紧邻输入区（距离缩短）；用带背景的 `role="alert"` 容器增强可见性。
  2. 错误提示内新增「收不到验证码？」帮助文案（检查手机号/短信拦截/重新获取）。
  3. 手机号输入框 `inputProps={{ inputMode: 'numeric', autoComplete: 'tel' }}`、验证码输入框 `inputProps={{ inputMode: 'numeric', autoComplete: 'one-time-code' }}`，移动端弹数字键盘。
- 微信扫码登录入口保持不变。

### 问题 7（低/P2）：左侧导航无障碍 —— 已修复

- **核实**：导航项在 v2.7.0 重构时已改用 MUI `ListItemButton`（`Layout.tsx`），键盘可聚焦（自带 role/tabindex），非纯 div。
- **修复内容**：为选中项补充 `aria-current={active ? 'page' : undefined}`，明确当前页语义，读屏可正确播报当前位置。

### 问题 8（低/P2）：设置页加载失败处理 —— 已修复

- **修复内容**（`SettingsPage.tsx`）：
  - 新增 `loadFailed` 状态；加载失败时（catch 分支）置 true。
  - 错误提示追加「（当前显示为默认值，加载失败前请勿保存）」。

### 问题 9（低/P3）：VS 路径占位符 + 自动检测 —— 已修复

- **修复内容**（`SettingsPage.tsx`）：
  - 占位符由过时的 `...\2022\Community\Common7\IDE\devenv.exe` 改为版本无关的 `C:\Program Files\Microsoft Visual Studio\20xx\Community`。
  - helperText 改为「留空则桌面伴侣自动检测；仅当自动检测失败时手动填写」。
