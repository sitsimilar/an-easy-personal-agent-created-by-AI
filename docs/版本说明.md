# 个人信息管家 · 版本说明

> **当前版本：v2.9.4**

「个人信息管家」是一款帮你管理个人零散信息、把想法展开成结构化思考的个人智能助手。它由两部分组成：一个**网页应用**（云端存数据），加上一个**常驻桌面的伴侣程序**（悬浮窗 + 系统托盘）。

---

## 一、这个软件能做什么（通俗总览）

把它当成你的「个人第二大脑」+「随身的代码审查助手」：

- **随手记**：想法、资料、待办，想到就记。它会自动帮你分类、写摘要，并把相关内容关联起来。
- **找得快**：关键词一搜就出来；还能自动提炼长文重点、整理待办、生成阶段总结和后续行动建议。
- **思维树**：输入一个主题或待解决的问题，沿「核心概念 / 前提与假设 / 可行性与风险 / 反面观点 / 下一步行动」五个维度生成分支，任意思考点可继续深挖成多级树；支持多棵树共存、归入「思维树林」组群，AI 自动识别跨树相关内容并给出交叉建议；每个思考点可添加文字备注。
- **桌面常驻**：一个置顶小悬浮窗 + 系统托盘，随时唤出、用完自动收起。
- **工具百宝箱**：在线跑 JS、编译调试 C++、自然语言生成代码、C# 速查库、截图识别。

## 二、当前版本（v2.9.4）功能清单

### 本版重点：全面优化（40 项修复）

- **VS 代码分析链路打通**：修复「VS 启动 → 读码 → 分析 → 推送优化建议」链路断点，产品核心卖点恢复可用。
- **安全加固**：桌面 IPC 特权接口补齐来源校验与路径沙箱，封堵远程页面越权执行本地命令 / 读取剪贴板的隐患。
- **全面修复 40 项审查问题**：覆盖功能完整性、交互体验、性能、稳定性、代码质量五大类（清除搜索失效、摘要/相关记录不刷新、启动无超时、检索注入转义、图片对象一致性、加载竞态、LLM 并发去重、假开关治理、无障碍、标签检索等），详见 `docs/全面审查报告.md`。

### 1. 信息记录与智能整理

- 记录「想法 / 资料 / 待办」三类信息
- 自动分类、自动摘要、智能关联相关内容
- 关键词检索
- 阶段总结 + 后续行动建议（行动项可一键转成待办）
- 重点信息提取、待办整理
- 各页面加载失败支持就地重试

### 2. 思维树 · 思维树林

- 五维度分支窗口：核心概念 / 前提与假设 / 可行性与风险 / 反面观点 / 下一步行动
- 任意思考点可继续深挖，形成多级树状结构；节点支持新增、展开/折叠、重新生成、删除
- 多树共存与保存：可创建多棵思维树并切换编辑，各自独立发展
- 思维树林：两棵及以上思维树可归入同一组群，自定义命名、手动添加/移除
- AI 交叉建议：自动识别跨树相关内容 → 经确认后建立交叉，交叉节点显示徽标与跨树伙伴列表
- 节点编辑区支持数位板（手写笔）输入与压感，笔迹随节点持久化
- 思维树/树林本地保存（自动迁移旧单树数据），AI 不可用时降级内置引导模板
- 思维树支持**导出 / 导入 JSON**（备份或跨设备迁移）

### 3. 桌面伴侣 · 悬浮窗

- 置顶悬浮窗 + 系统托盘常驻
- 可拖动、可贴边隐藏、5 秒无交互自动收起（悬停唤醒）
- 原生主窗口 + 自定义标题栏（最小化 / 最大化 / 关闭）
- 全局右键菜单（复制 / 粘贴 / 剪切 / 全选）

### 4. 工具箱

- 读取选区文本分析
- 速查库：C# 常用关键字 / 运算符 / 语法 / 函数速查（122 条，分类浏览 + 搜索 + 一键复制）
- **C++ 速查库**：C++ 常用语法 / 标准库 / 常用算法 / 内存管理 / 常见陷阱（分类浏览 + 搜索 + 一键复制），与 C# 速查库并列
- 代码生成：用自然语言描述需求，自动生成完整可运行的 C++ 代码（跨 MSVC / MinGW / GCC 兼容，内置算法能力）
- IDE 模式：在线编写并运行 JavaScript；编译、运行、调试 C++
- 截图识别：上传截图 + 描述，AI 识别内容并推测需求

### 5. IDE 模式 · C++

- 编写 C++ 代码 → 编译 → 运行 → 调试，一条龙
- 真调试：断点、单步跳过、单步进入、查看局部变量与调用栈
- 自动识别电脑里的编译工具：**优先用 Visual Studio（cl + cdb），没有 VS 时自动退回 MinGW（g++ + gdb）**
- 一键部署 MinGW：点一下自动下载便携工具链到应用目录，免管理员、免手动配置

### 6. 设置与数据

- 云端存储，按账号隔离
- 数据存储位置查看与管理
- AI 分析模型「速度优先 / 质量优先」开关
- 一键删除（卸载时保留云端数据）

## 三、版本号与安装包命名规则

- 版本号采用「主版本 . 次版本 . 修订号」格式，统一写在项目各 `package.json` 的 `version` 字段里。
- **安装包一律按当前版本号命名**：
  | 类型  | 命名格式                     | 当前版本（v2.9.4）             |
  | --- | ------------------------ | ------------------------ |
  | 安装版 | `个人信息管家 Setup {版本号}.exe` | `个人信息管家 Setup 2.9.4.exe` |
- 以后每次发版，只需递增 `version` 字段（例如 `2.8.0 → 2.8.1`），安装包名称会自动带上新版本号，无需手动改文件名。
