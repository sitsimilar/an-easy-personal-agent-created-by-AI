# 洛谷算法竞赛题目清单（强化 C++ 代码生成能力）

> 目标：覆盖 **入门 / 普及 / 提高 / 省选 / NOI** 五个难度等级，每个等级 6 道代表性题目，
> 共 30 题。每道题均需提供：题目链接、难度标签、核心算法/数据结构，并配套**本地验证可通过**、
> 注释充分、跨编译器（MSVC cl / MinGW g++ / GCC，C++17）可编译的解答代码。

## 编译与验证环境

- 编译器：`C:/msys64/ucrt64/bin/g++.exe`（MinGW-w64 UCRT，g++ 16.2）
- 关键点：
  - 编译前必须 `export PATH="/c/msys64/ucrt64/bin:$PATH"`（否则 g++ 找不到自身 DLL，静默失败）
  - **不提供 `<bits/stdc++.h>`**，必须逐个显式 include 所需标准头文件
  - 输出可执行文件必须用 **ASCII 路径**（中文路径会导致链接器报 `cannot open output file`）
- 统一编译参数：`g++ -std=c++17 -O2 -o <ASCII路径>/pXXXX.exe pXXXX.cpp`
- 验证方式：编译通过 + 运行官方样例（样例输入 → 样例输出一致）；简单题额外用随机小数据与暴力对拍。

| 3 | [NOIP2005 普及组] 陶陶摘苹果 | P1046 | 数组遍历 |

### 题目详情

1. **P1001 A+B Problem**（入门）— https://www.luogu.com.cn/problem/P1001
   - 输入两个整数 a, b（|a|,|b| ≤ 10^9）；输出 a+b。
2. **P1035 级数求和**（入门）— https://www.luogu.com.cn/problem/P1035
   - 输入整数 K（1 ≤ K ≤ 15）；输出最小的 n 使 1 + 1/2 + 1/3 + … + 1/n > K。
3. **P1046 陶陶摘苹果**（入门）— https://www.luogu.com.cn/problem/P1046
   - 第一行 10 个整数（苹果高度 100~200）；第二行 1 个整数（手伸直高度 100~120，踩 30cm 凳子）。输出能摘到的苹果数。
4. **P1085 不高兴的津津**（入门）— https://www.luogu.com.cn/problem/P1085
   - 7 行，每行两个整数（在校时长、课外时长）。输出最不高兴的一天（1~7）；若每天都 ≤ 8 小时则输出 0。
5. **P1055 ISBN 号码**（入门）— https://www.luogu.com.cn/problem/P1055
   - 一行 ISBN-10：`x-xxx-xxxxx-x`（校验位为数字或 X）。校验并判断是否正确：正确输出 `Right`，否则输出正确的 ISBN 号码。
6. **P1089 津津的储蓄计划**（入门）— https://www.luogu.com.cn/problem/P1089
   - 12 行每月预算。每月 300 元，剩余整百存妈妈处，年末返 120%。若某月不够，输出 `-月份`（如 `-7`）；否则输出年末总钱数。

### 题目详情

7. **P1012 拼数**（普及-）— https://www.luogu.com.cn/problem/P1012
   - 第一行 n（≤ 20），第二行 n 个正整数（≤ 10^9）。将它们拼接成**最大**整数输出。
8. **P1048 采药**（普及-）— https://www.luogu.com.cn/problem/P1048
   - 第一行 T（≤ 1000）M（≤ 100）；接下来 M 行每行时间 t、价值 v。输出不超过 T 时间的最大总价值。
9. **P1177 快速排序**（普及-）— https://www.luogu.com.cn/problem/P1177
   - 第一行 n（≤ 10^5）；第二行 n 个整数（|x| ≤ 10^9）。升序输出（空格分隔）。
10. **P1216 数字三角形**（普及-）— https://www.luogu.com.cn/problem/P1216
    - 第一行 r（≤ 1000）；接下来 r 行数字三角形。输出从顶到底的最大路径和。
11. **P1028 数的计算**（普及-）— https://www.luogu.com.cn/problem/P1028
    - 输入 n（≤ 1000）。合法序列：以 n 开头，每个数可在其左边接一个不超过它一半的数。输出合法序列总数。
12. **P1223 排队接水**（普及-）— https://www.luogu.com.cn/problem/P1223
    - 第一行 n（≤ 1000）；第二行 n 个接水时间。输出最小平均等待时间（保留 2 位小数）与最优排队顺序（按输入下标）。

### 题目详情

13. **P3372 线段树 1**（提高-）— https://www.luogu.com.cn/problem/P3372
    - n, m（≤ 10^5）；n 个数；m 个操作：`1 l r k`（区间加 k）或 `2 l r`（区间求和）。输出每次求和结果。
14. **P3375 KMP 字符串匹配**（提高-）— https://www.luogu.com.cn/problem/P3375
    - 两行：s1（主串）、s2（模式串）。输出所有匹配位置（从 1 开始），再输出 s2 的 next 数组（prefix 数组）。
15. **P3379 最近公共祖先（LCA）**（提高-）— https://www.luogu.com.cn/problem/P3379
    - n（≤ 5×10^5）、m、s（根）；n-1 条无向边；m 个询问 (u,v)。输出每个询问的 LCA。
16. **P3371 单源最短路径（弱化版）**（提高-）— https://www.luogu.com.cn/problem/P3371
    - n（≤ 10^4）、m（≤ 5×10^5）、s；m 条有向边 (u,v,w)，w ≥ 0。输出 s 到各点最短路，不可达输出 2147483647。
17. **P3385 负环**（提高+）— https://www.luogu.com.cn/problem/P3385
    - T 组；每组 n、m，m 条有向边 (u,v,w)，w 可为负。存在负环输出 `YES`，否则 `NO`。
18. **P3374 树状数组 1**（普及+/提高）— https://www.luogu.com.cn/problem/P3374
    - n（≤ 5×10^5）、m；n 个数；m 个操作：`1 x k`（第 x 个数加 k）或 `2 x y`（求 [x,y] 和）。

### 题目详情

19. **P3384 树链剖分**（省选/NOI-）— https://www.luogu.com.cn/problem/P3384
    - n、m、r、p；n 个点权；n-1 条边；m 个操作：`1 x y z`（x→y 路径加 z）、`2 x y`（路径和）、`3 x z`（x 子树加 z）、`4 x`（x 子树和）。结果对 p 取模。
20. **P3834 主席树**（提高+/省选-）— https://www.luogu.com.cn/problem/P3834
    - n（≤ 2×10^5）、q；n 个数；q 个询问 `l r k`（区间 [l,r] 第 k 小值）。
21. **P3373 线段树 2**（提高+/省选）— https://www.luogu.com.cn/problem/P3373
    - n、q、m；n 个数；q 个操作：`1 l r k`（区间乘 k）、`2 l r k`（区间加 k）、`3 l r`（区间和）。结果对 m 取模。
22. **P3389 高斯消元法**（提高+）— https://www.luogu.com.cn/problem/P3389
    - n（≤ 100）；n 行 n+1 列增广矩阵。有唯一解输出 n 个解（保留 2 位小数），否则输出 `No Solution`。
23. **P3388 割点（割顶）**（提高+）— https://www.luogu.com.cn/problem/P3388
    - n（≤ 2×10^4）、m（≤ 10^5）；m 条无向边。第一行输出割点个数，第二行升序输出所有割点编号。
24. **P3803 多项式乘法（FFT）**（提高+/省选-）— https://www.luogu.com.cn/problem/P3803
    - n、m（≤ 10^6）；两行多项式系数（长度 n+1、m+1）。输出卷积结果（长度 n+m+1）各项系数。

### 题目详情

25. **P3376 网络最大流**（提高+/省选）— https://www.luogu.com.cn/problem/P3376
    - n（≤ 200）、m（≤ 5000）、s、t；m 条有向边 (u,v,w)，w ≤ 10^6。输出 s→t 最大流。
26. **P4717 FWT**（省选/NOI-）— https://www.luogu.com.cn/problem/P4717
    - n（< 18）；两行各 2^n 个整数 A、B。分别输出或卷积、与卷积、异或卷积结果（各 2^n 个数），mod 998244353。
27. **P3391 文艺平衡树**（省选/NOI-）— https://www.luogu.com.cn/problem/P3391
    - n（≤ 10^5）、m；初始序列 1..n；m 个操作 `l r`（翻转区间 [l,r]）。输出最终序列。
28. **P3690 动态树（LCT）**（NOI/NOI+）— https://www.luogu.com.cn/problem/P3690
    - n（≤ 10^5）、m；n 个点权；m 个操作：`0 x y`（x→y 路径异或和）、`1 x y`（连边）、`2 x y`（断边）、`3 x y`（改点权为 y）。
29. **P4180 严格次小生成树**（省选/NOI-）— https://www.luogu.com.cn/problem/P4180
    - n（≤ 10^5）、m（≤ 3×10^5）；m 条无向边 (u,v,w)，w ≤ 10^9。输出严格次小生成树边权和。
30. **P1903 数颜色 / 维护队列**（省选/NOI）— https://www.luogu.com.cn/problem/P1903
    - n、m；n 个颜色；m 个操作：`Q l r`（查询区间不同颜色数）或 `R p c`（单点改颜色）。输出每次查询结果。
