> 给出**通用模板、关键实现要点、复杂度**，作为 C++ 代码生成时的算法知识底座。

## 0. 通用优化技巧（贯穿所有题）

| 技巧 | 说明 |
|------|------|
| `long long` 防溢出 | 求和、计数、乘法结果可能超 `int`（约 2.1×10⁹）时一律用 `long long` |
| 排序用 `std::sort` | 内省排序，最坏 O(n log n)；手写朴素快排最坏 O(n²) 会被卡 |
| `std::ios::sync_with_stdio(false)` | 关闭 C/C++ 流同步 + `cin.tie(nullptr)`，大数据输入提速数倍 |
| 显式 include、不用 `bits/stdc++.h` | 跨编译器（MSVC/MinGW/GCC）可移植，编译更快 |
| 递归防爆栈 | 深树/长链的递归（DFS、线段树递归、LCA）改用迭代或手动扩栈 |
| 减少常数 | 邻接表优于邻接矩阵；vector 预 `reserve`；避免频繁动态分配 |
| 离线 + 离散化 | 值域大但数据量小时先排序去重离散化，再用下标建数据结构 |

## 1. 基础与模拟

- **级数求和**：用 `double` 累加 `1.0/i`，注意浮点比较用 `sum <= K` 而非 `==`。
- **模拟类（储蓄计划/ISBN/津津）**：按题意逐步模拟，关键在**边界**（如月份不够钱提前输出 `-月份`、校验位 10 → `'X'`）。
- 复杂度：O(题目步数)，几乎不优化，重点是**读题与边界不漏**。

## 2. 排序与贪心

### 2.1 快速排序 / 一般排序
```cpp
std::sort(v.begin(), v.end());          // 升序
std::sort(v.begin(), v.end(), std::greater<>()); // 降序
```
- 复杂度 O(n log n)；自定义比较器必须满足严格弱序（`a < b`）。

### 2.2 拼数（自定义排序）
按拼接结果比较：`return a + b > b + a;`（把「组成最大数」转化为排序规则）。

### 2.3 排队接水（短作业优先 SJF）
按用时升序排队即可最小化平均等待时间；用**稳定排序**保证同值时的输入顺序唯一。

### 2.4 贪心通用套路
- 证明「局部最优 → 全局最优」（交换论证 / 反证）。
- 常配合排序、优先队列（`std::priority_queue`）。

## 3. 动态规划

### 3.1 0-1 背包（采药）
```cpp
std::vector<long long> dp(T + 1, 0);
for (int i = 0; i < M; ++i)
  for (int j = T; j >= t[i]; --j)          // 逆序：保证每件只用一次
    dp[j] = std::max(dp[j], dp[j - t[i]] + v[i]);
```
- 复杂度 O(M·T)，空间 O(T)（滚动数组）。
- 关键：**容量逆序遍历**；完全背包则正序。

### 3.2 数字三角形（自底向上）
```cpp
for (int i = r - 2; i >= 0; --i)
  for (int j = 0; j <= i; ++j)
    a[i][j] += std::max(a[i+1][j], a[i+1][j+1]);
```
- 从倒数第二层向上累加，答案在 `a[0][0]`；避免自顶向下记录路径。

### 3.3 递推 + 前缀和（数的计算）
`f[i] = f[i-1] + f[i/2]`（或定义式 + 前缀和优化），把 O(n²) 降到 O(n)。

### 3.4 DP 通用要点
- 明确状态定义、转移方程、初始化、边界、答案位置。
- 记忆化搜索（递归 + 缓存）适合状态转移顺序不直观的题。

## 4. 图论

### 4.1 单源最短路
- **Dijkstra（非负权，堆优化）** O((n+m) log n)：
```cpp
std::priority_queue<std::pair<long long,int>,
  std::vector<std::pair<long long,int>>, std::greater<>> pq;
dist[s] = 0; pq.push({0, s});
while (!pq.empty()) {
  auto [d, u] = pq.top(); pq.pop();
  if (d != dist[u]) continue;              // 惰性删除
  for (auto [v, w] : g[u]) if (dist[u] + w < dist[v]) {
    dist[v] = dist[u] + w; pq.push({dist[v], v});
  }
}
```
- **SPFA（可负权）**：队列优化 Bellman-Ford，最坏 O(n·m)，但判负环常用。
- **判负环**：维护 `cnt[v]`（松弛次数），`cnt[v] >= n` 则有负环；为防图不连通，建虚拟源点向所有点连 0 边。

### 4.2 最小生成树（Kruskal）
边按权升序 + 并查集判环，复杂度 O(m log m)。

### 4.3 最近公共祖先（倍增 LCA）
```cpp
// 预处理 depth[] 与 up[u][k]（u 的 2^k 级祖先）
// 查询：先提升到同深度，再一起向上跳
```
- 预处理 O(n log n)，单次查询 O(log n)。
- 深树用**迭代 BFS/循环**预处理，避免递归爆栈。

### 4.4 连通性 / 割点（Tarjan）
`dfn[u]` 与 `low[u]`；割点判定：
- 根节点：子树数 ≥ 2；非根：存在子节点 v 使 `low[v] >= dfn[u]`。

### 4.5 拓扑排序
入度为 0 入队，依次出队删边；用于 DAG 上的 DP / 判环。

## 6. 数据结构

### 6.1 并查集
```cpp
int find(int x){ return fa[x]==x ? x : fa[x]=find(fa[x]); } // 路径压缩
void unite(int x,int y){ int rx=find(x),ry=find(y); if(rx!=ry) fa[rx]=ry; }
```
- 可加**按秩/大小合并**，均摊近 O(1)。

### 6.2 树状数组（单点改 + 区间和）
```cpp
void add(int i, long long x){ for(; i<=n; i+=i&-i) c[i]+=x; }
long long sum(int i){ long long s=0; for(; i>0; i-=i&-i) s+=c[i]; return s; }
// 区间 [l,r] 和 = sum(r) - sum(l-1)
```
- 复杂度 O(log n)。

### 6.3 线段树（区间改 + 区间查，懒标记）
```cpp
// 核心：build / pushup / pushdown(懒标记下传) / update / query
// 懒标记：区间加 k 时 tag += k，访问前 pushdown
```
- O(log n) 每操作。**开 4 倍空间**；区间和用 `long long`。

### 6.4 线段树 2（双懒标记：乘 + 加）
- 懒标记为 `(mul, add)`；下传顺序：`sum = sum*mul + add*len`。
- 处理区间乘时 `mul *= k; add *= k`（先乘后加原则）。

### 6.5 主席树（可持久化线段树，区间第 k 小）
- 对值域离散化，每个前缀建一棵线段树，`root[i]` 由 `root[i-1]` 新增一条链得到（可持久化）。
- 查询 [l,r] 第 k 小：`root[r]` 与 `root[l-1]` 作差后在线段树上二分。
- 复杂度 O((n+q) log n)。

### 6.6 平衡树（文艺平衡树，区间翻转）
- 用 **FHQ-Treap**（按大小分裂 + 合并 + 懒翻转标记）实现区间操作，代码比 Splay 简洁。
- 翻转区间 [l,r]：按大小分裂出 [l,r] 子树 → 打懒标记 → 合并回。

### 6.7 树链剖分（路径/子树操作）
- 重链剖分：第一次 DFS 求 size/重儿子，第二次 DFS 分配新编号使**重链、子树编号连续**。
- 路径操作拆成若干段重链上的线段树区间操作；子树 = 一段连续区间 `[dfn[x], dfn[x]+size[x]-1]`。
- 复杂度 O(log² n) 每次路径操作。

### 6.8 Link Cut Tree（动态树）
- 用 Splay 维护实链 + `access/makeroot/findroot/split/link/cut`。
- 路径查询用 `split(x,y)` 后取 Splay 根节点信息；支持动态加边/删边。

## 7. 数学

### 7.1 高斯消元（解线性方程组）
- 选主元（绝对值最大行）→ 消元 → 回代。
- 无解/多解判定：某行系数全 0 而常数非 0 则无解；系数与常数均 0 则多解。
- 复杂度 O(n³)；保留小数时注意精度（输出保留 2 位）。

### 7.2 FFT / NTT（多项式卷积）
- FFT：`std::complex<double>` + 蝴蝶变换，O(n log n)，有浮点精度误差。
- NTT：原根代替单位根，模意义下精确，常用模数 998244353（原根 3）。
- 卷积结果长度 = 两多项式长度和 − 1。

### 7.3 FWT（位运算卷积）
- 对或 / 与 / 异或卷积，各有一套变换 + 逆变换；复杂度 O(n·2^n)。
- 异或卷积：`(a+b, a-b)` 的蝶形变换，逆变换乘 1/2。

## 9. 进阶技巧

### 9.1 严格次小生成树
- 先 Kruskal 求最小生成树；对每条非树边 (u,v,w)，找树上 u→v 路径的最大边 / 严格次大边（倍增 LCA 同时维护最大与次大）。
- 用「次大边」避免 `w == 最大边` 时退化为非严格次小。

### 9.2 带修莫队（数颜色 / 维护队列）
- 在普通莫队上增加**时间维**；块大小取 `n^(2/3)`，复杂度约 O(n^(5/3))。
- 移动指针时按「左右端点 + 时间」三维调整，处理修改用「交换法」回滚。

### 9.3 离线与数据预处理
- 询问可离线时，常配合排序、前缀和、离散化、扫描线降低复杂度。
